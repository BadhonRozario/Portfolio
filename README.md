# Badhon Rozario - Portfolio

A responsive multi-page portfolio built with HTML, CSS, and JavaScript. No package installation or build step is required.

## Preview locally

Open `index.html` in a browser, or use a local static server such as VS Code Live Server.

## Pages

- `index.html` - Home and selected work
- `about.html` - Profile and education history
- `skills.html` - Technical skills
- `projects.html` - Academic and personal projects, plus thesis research
- `experience.html` - City Bank internship and IUBAT IT Society leadership
- `contact.html` - Contact details and email draft form

## Before publishing

- Confirm the email address, phone number, and social profile URLs.
- Add project source/demo links if you want them public.
- Keep image paths and filename capitalization consistent. The profile photo is `Images/Badhon.jpg`.
- Reference contact details are intentionally excluded from the public portfolio.

## GitHub Pages

This is a static site and can be hosted from a GitHub repository. Push the project, then open **Settings -> Pages**, select the branch and root folder, and save.
